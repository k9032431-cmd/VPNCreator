# VPN Creator — Telegram-бот для создания VPN-ключей

Бот подключается к вашим VPS по SSH, один раз устанавливает ваш скрипт и затем по кнопке создаёт ключи.

## Возможности

- **Главное меню**: Создать ключ · Мои ключи · Мои серверы · Подключить VPS · Настройки · Помощь · Админ-панель
- **Цветные кнопки** (синие / зелёные / красные) и **премиум-эмодзи** в текстах и на кнопках
- **Подключение VPS** пошагово: IP → порт → логин → пароль или SSH-ключ → название. Бот проверяет подключение, сообщения с паролем сразу удаляет, пароли/ключи хранит зашифрованными
- **Создание ключа**: выбор сервера → название → бот загружает скрипты, выполняет команды установки (только один раз на сервер), затем команду создания ключа и присылает ключ с кнопкой «Копировать»
- **Настройки (админ)**: загрузка скриптов, команды установки, команда создания/удаления ключа, фильтр вывода (regex), баннер главного меню, «переустановить на всех серверах»
- **Админ-панель**: заявки на доступ (одобрить/отклонить), пользователи, выдача доступа по ID, назначение админов, блокировка, статистика
- **ID премиум-эмодзи**: админ отправляет боту сообщение с премиум-эмодзи — бот отвечает их ID

## Как работает установка

1. Админ в «Настройках» загружает скрипт(ы) и задаёт команды, например:
   - Установка (каждая строка — шаг): `bash {script} install`
   - Создание ключа: `bash {script} add {name}`
   - Удаление ключа: `bash {script} del {name}`
   - Фильтр ключа: `vless://\S+`
2. При первом ключе на сервере бот загружает файлы в `~/vpncreator/` и выполняет шаги установки.
3. Дальше на этом сервере выполняется только команда создания ключа.
4. Если админ поменял скрипты или команды установки — версия конфигурации растёт, и каждый сервер переустановится при следующем ключе.

Подстановки: `{name}`, `{script}`, `{dir}`, `{server_ip}`, `{user_id}`. Все команды выполняются из `~/vpncreator`.

## Запуск

```bash
cp .env.example .env   # заполните BOT_TOKEN, ADMIN_IDS, SECRET_KEY
```

**Docker:**
```bash
docker compose up -d --build
```

**Без Docker:**
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m bot
```
Для автозапуска есть `deploy/vpncreator.service` (systemd, путь `/opt/VPNCreator`).

## Премиум-эмодзи

Все эмодзи — в `bot/emoji.py`: `имя: ("обычный", "ID премиум")`. Пустой ID — показывается обычный эмодзи.
Чтобы премиум-эмодзи отображались, у владельца бота должен быть Telegram Premium
(для эмодзи в тексте сообщений Telegram также может требовать купленный на Fragment username бота).
