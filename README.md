# OpenVPN Creator — Telegram-бот для создания VPN-ключей

Бот подключается к вашим VPS по SSH, один раз устанавливает ваш скрипт и затем по кнопке создаёт ключи.

## Возможности

- **Главное меню**: Создать ключ · Мои ключи · Мои серверы · Подключить VPS · Настройки · Помощь · Админ-панель
- **Цветные кнопки** (синие / зелёные / красные) и **премиум-эмодзи** в текстах и на кнопках
- **Подключение VPS** пошагово: IP → порт → логин → пароль или SSH-ключ → название. Бот проверяет подключение, сообщения с паролем сразу удаляет, пароли/ключи хранит зашифрованными
- **Создание ключа**: выбор сервера → выбор VPN (если скриптов несколько) → название → бот один раз устанавливает скрипт, создаёт ключ и присылает файл (`.ovpn`) или текст с кнопкой «Копировать»
- **Несколько ключей за раз**: названия списком (каждое с новой строки) или просто число — бот создаст все ключи за одно подключение и пришлёт файлы альбомом
- **Серверы без root (Azure, AWS, GCP…)**: если логин не `root`, бот сам выполняет всё через `sudo` (вводит пароль от сервера, если sudo его спрашивает)
- **Скрипты VPN — только в админ-панели**: мастер «название → файл или ссылка → шаги установки → проверка → шаги создания ключа → где взять ключ», удаление ключа, включение/выключение, «переустановить везде»
- **Админ-панель**: заявки на доступ (одобрить/отклонить), пользователи, выдача доступа по ID, назначение админов, блокировка, статистика, баннер
- **ID премиум-эмодзи**: админ отправляет боту сообщение с премиум-эмодзи — бот отвечает их ID

## Как бот выполняет скрипт

Бот открывает на сервере **настоящий терминал** и «печатает» шаги по одному — как человек:
каждая строка вводится, когда скрипт ждёт ответа. Поэтому интерактивные скрипты (с вопросами) работают без переделок.

- Строки — это команды и ответы вперемешку, в том порядке, в каком вы печатали бы их сами
- `enter` — просто нажать Enter (оставить значение по умолчанию)
- Подставленное скриптом значение по умолчанию стирается перед вводом ответа
- На «Press any key» отправляется одна клавиша
- Если команда упала — оставшиеся шаги не вводятся, бот показывает вывод
- Если скрипт ждёт ответа, а шаги закончились — бот показывает, на каком вопросе он остановился

Подстановки: `{name}` — название ключа, `{file}` — путь к файлу скрипта, `{server_ip}`, `{user_id}`.
Команды выполняются в папке `~/vpncreator`, куда загружен файл скрипта.

### Пример: OpenVPN (скрипт angristan/openvpn-install)

| Поле | Значение |
|---|---|
| Название | `OpenVPN` |
| Файл | файл `vpn` или ссылка на него |
| Установка | `chmod +x vpn` · `./vpn` · `enter` · `n` · `2` · `443` · `1` · `11` · `n` · `y` · `3` · `2` ×7 · `v` · `admin` · `enter` (каждое — с новой строки) |
| Проверка | `test -f /etc/openvpn/server.conf` |
| Создание ключа | `./vpn` · `1` · `{name}` · `enter` |
| Результат | файл `/root/{name}.ovpn` |
| Удаление ключа | `cd /etc/openvpn/easy-rsa && ./easyrsa --batch revoke {name} && EASYRSA_CRL_DAYS=3650 ./easyrsa gen-crl && cp pki/crl.pem /etc/openvpn/crl.pem && chmod 644 /etc/openvpn/crl.pem && rm -f /root/{name}.ovpn` |

## Установка одной командой

Сервер: Ubuntu 20.04+ / Debian 11+, вход под root.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/k9032431-cmd/VPNCreator/HEAD/install.sh)
```

Скрипт спросит токен бота и ваш Telegram ID, сам поставит всё нужное, сгенерирует `SECRET_KEY`,
создаст сервис systemd (автозапуск, перезапуск при сбое) и команду `vpncreator`.

Без вопросов:
```bash
BOT_TOKEN=123456:ABC... ADMIN_IDS=111111111 bash <(curl -fsSL https://raw.githubusercontent.com/k9032431-cmd/VPNCreator/HEAD/install.sh)
```

Управление:

| Команда | Что делает |
|---|---|
| `vpncreator status` | статус бота |
| `vpncreator logs` | логи в реальном времени |
| `vpncreator restart` / `stop` / `start` | перезапуск / остановка / запуск |
| `vpncreator update` | обновить из GitHub (настройки и база сохраняются) — то же, что кнопка в боте |
| `vpncreator config` | сменить токен, админов, название |
| `vpncreator backup` | архив базы и `.env` в `/root` |
| `vpncreator uninstall` | удалить бота полностью |

Файлы: код — `/opt/VPNCreator`, база — `/opt/VPNCreator/data/bot.db`, настройки — `/opt/VPNCreator/.env`.

### Обновление бота одной кнопкой

Админ-панель → **🔄 Обновить бота**: бот покажет, что нового на GitHub, и по кнопке «Обновить сейчас»
скачает новую версию и перезапустится (≈1–3 минуты). Пользователи, серверы, ключи и скрипты сохраняются.
Когда появляется новая версия, бот сам напишет админам (проверка раз в 6 часов).

Как это устроено: бот работает без root и сам себя не обновляет — он кладёт файл-заявку
`data/update.request`, а systemd-юнит `vpncreator-update.path` запускает от root `install.sh _auto_update`
(то же, что `vpncreator update`). Итог бот присылает админу, нажавшему кнопку.

> Если бот был установлен до появления этой кнопки — один раз выполните на сервере `vpncreator update`.

### Docker (альтернатива)

```bash
cp .env.example .env   # заполните BOT_TOKEN, ADMIN_IDS, SECRET_KEY
docker compose up -d --build
```

## Премиум-эмодзи

Все эмодзи — в `bot/emoji.py`: `имя: ("обычный", "ID премиум")`. Пустой ID — показывается обычный эмодзи.
Чтобы премиум-эмодзи отображались, у владельца бота должен быть Telegram Premium
(для эмодзи в тексте сообщений Telegram также может требовать купленный на Fragment username бота).
